DETAILED REFERENCE ARCHITECTURE

One conversational analytics turn

The workflow has a fixed maximum fan-out, explicit state transitions, validated contracts, read-only execution, and a hard distinction between model-generated plans and executable analytical code.

Pause paths: essential ambiguity becomes a persisted clarification turn. Missing analytical data or models becomes a bounded, explainable blocked result. Externally visible actions would use Runtime approval and tool-ledger semantics.
Termination: 2 clarifications, 3 query tasks, per-agent step/token/cost/time budgets, finite retries, cancellable execution.
